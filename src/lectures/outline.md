# AI Missing Semester · 课程大纲

**补齐前置知识，把 AI 用好。** 学员定位与完成标准见[意向书](../../.42cog/intent.md)；不要求编程或机器学习先修。

核心课 6 讲，采用工作坊形式，每讲有实操。第一讲建立最小全局认识，第六讲综合应用。小节按“讲次.节次”编号，便于选择单点细化；每讲知识清单不超过 200 字。操作用于观察和验证知识。选题与补充依据见[缺失基础研究](../../docs/research/005_missing-foundations/README.md)，AICourse 衔接见[对齐研究](../../docs/research/004_aicourse-alignment/README.md)。

## 第 1 讲 · AI 使用的最小全局认识

- **1.1 AI 的组成**：模型、应用框架（Harness）、上下文、工具与人的关系。
- **1.2 生成机制**：训练与推理，概率生成及知识边界。
- **1.3 能力来源**：生成、检索、计算和工具执行的区别。
- **1.4 人机分工**：指令、材料、判断与责任。

## 第 2 讲 · 文本、Markdown 与网页基础

- **2.1 文本与编辑**：纯文本、编辑器、源文与预览。
- **2.2 Markdown 语法**：标题、列表、强调、链接、引用与代码块。
- **2.3 结构化说明**：要求、材料、步骤与示例的组织。
- **2.4 Skill 文件**：Markdown 正文与 YAML 元数据的分工，读改说明。
- **2.5 网页语言**：HTML、CSS、JavaScript 的结构、样式与交互分工。

## 第 3 讲 · 文件、数据格式与 Git

- **3.1 文件与路径**：文件夹、扩展名、绝对／相对路径。
- **3.2 格式与解析**：文本、文档、扫描件；改后缀不等于转换。
- **3.3 JSON**：键值、列表、类型，读懂结构化结果。
- **3.4 YAML**：键值、列表、缩进，读改最小配置。
- **3.5 Git 与版本**：仓库、原件、暂存、提交快照、历史、差异与恢复。
- **3.6 分支与远端**：分支、合并、冲突；Git 与 GitHub、远端同步与备份的区别。

## 第 4 讲 · 浏览器、上下文与资料取用

- **4.1 浏览器与网址**：浏览器、网站与服务器；URL 协议、域名、路径；本地文件／网络地址。
- **4.2 输入容量**：token 与上下文窗口。
- **4.3 信息位置**：聊天历史、本轮上下文、外部记忆与资料库。
- **4.4 资料取用**：读取、解析、检索、进入上下文；网页可见与实际取材。
- **4.5 按需加载**：索引、文件引用与本轮可见内容。
- **4.6 来源判断**：训练知识、材料事实、生成推断；核对原文及版本。

## 第 5 讲 · 工具、命令与运行环境

- **5.1 工具与 API**：请求、参数、返回与错误；描述操作和实际执行的区别。
- **5.2 命令与终端**：程序、参数、工作目录与输出。
- **5.3 运行环境**：本机／云端、安装／运行、依赖与版本。
- **5.4 权限与状态**：访问范围、登录授权、Cookie、缓存、扩展权限；密钥用途与保管。
- **5.5 网络与调试**：端口、HTTP 请求／响应、状态码；Console、Network 的用途。

## 第 6 讲 · 基础知识的综合应用

- **6.1 文件辨读**：解释资料或工作说明的结构与引用。
- **6.2 配置修改**：改动必要字段，说明语法和适用位置。
- **6.3 结果判断**：区分格式合法、事实可靠与操作完成。
- **6.4 理解迁移**：换材料或工具，依据原理预测行为并验证。

## 材料、选修与交付

前五讲共享事实材料，各讲独立提供输入并配替换题；第六讲更换任务或资料。多模态核心课辨用途，完整操作放选修。

Git 与浏览器基础为核心内容；HTML／GUI Git 二择一微练习沿用已有约定。命令、网络与环境先辨机制，实际安装与连接路径经小样决定；完整 Skill 封装、MCP 配置和前端开发留后续学习。

主题选修最多 4 讲：图像与声音、表格与数据、个人知识库、Agent 与自动化；具体范围待定。

最终形成讲义、教学 PPTX 与交互自学内容，共用目标、材料和判据。实际课时、工具路径与教学效果经小样和试教确定；交付标准见[课程标准](../../specs/course.md)。

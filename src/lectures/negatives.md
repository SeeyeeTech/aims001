范围仅限 [大纲](outline.md)；对应 [standard.md](standard.md) 的三条硬约束。

## 事后 · 从本轮退回的稿件抽取

用户先选择 Git 基线的表达，继而认可全部基础知识，现已亲改第 2—5 讲的分组。保留表达原则，按最新亲改调整知识位置。

三条正向约束对应十八条负例，超过三倍。Git 基线只作表达参照；编号、字数和词组检查不能替代知识关系与教学范围判断。

## 事前 · 主动攻击

试着删掉知识、搬回旧讲次、加入错误等式或长解释；检查必须失败。合理节名调整应通过。实际反例冒烟结果记入状态板，不把脚本通过当作教学效果。

## PATTERNS

每行是 Python 正则、一个 TAB 和说明；只扫描六讲正文。结构与字数由同目录 `check.sh` 检查。

```PATTERNS
\{\{[^}]*\}\}	未填写的模板占位
(?:掌握|实操|练习)\s*(?:Skill|MCP|Hook)\s*(?:封装|配置|部署)	提前加入完整封装或配置目标
(?:搭建|部署)\s*(?:完整\s*)?(?:Agent|智能体|AI\s*自主)\s*系统	提前加入系统搭建目标
(?:docx|DOCX)\s*(?:是|属于)\s*纯文本	docx 包被误判为纯文本
(?:PDF|pdf)\s*(?:都是|就是|等于)\s*(?:图片|扫描件)	PDF 被误判为全是图片或扫描件
(?:改|修改)(?:扩展名|后缀)(?:即可|就能|等于)(?:完成)?(?:转换|转码)	改名被误判为格式转换
(?:同步|Git)\s*(?:就是|等于)\s*(?:完整)?备份	版本或同步被误判为完整备份
(?:上传|引用)(?:资料|文件)?(?:成功)?(?:就|即)(?:全部)?(?:进入|占用)上下文	上传或引用被误判为完整上下文
SSH\s*(?:就是|等于)\s*(?:远程桌面|控桌面)	SSH 被误判为远程桌面
(?i)\bSkills?\b	已撤回的 Skill 课程内容
训练|微调	超出 AI 应用范围的模型训练内容
```

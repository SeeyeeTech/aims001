# AI Missing Semester · 意向书

状态：用户已纠正受众定位，课程深度据此修订；2026-10-13。

## 收敛方向（唯一）

帮助经常使用 AI、但缺少系统前置知识的学习者理解并排除使用中的困惑、阻碍与偏差，稳定完成可检查、可使用的真实任务。

怎么算数：每讲对应一个常见使用偏差、一组解释偏差所需的前置知识和一件可验收的修复成果；学习者能定位失败环节，用对照操作验证判断，并解释方法的适用边界。学习者能在减少教师帮助后，把方法迁移到另一件类似任务；会背术语不计作完成。具体达成率由首轮目标学员试教定标。

## 真难题

当前待验证的教学难题：如何从偶然得到好答案，转变为稳定说明需求、提供材料、发现错误并完成交付；如何在产品和界面不断变化时，仍让学习者学会可迁移的方法。这些是研究假设，尚无多年追踪证据。

## 不做什么

| 不做 | 为什么不做 |
|---|---|
| 把机器学习原理、编程基础作为先修课 | 不预设学员具备这些基础；解释使用偏差所需的机制在课内补齐，不要求先完成机器学习或编程课程 |
| 按术语目录或厂商功能清单安排主线 | 理解名词不等于能够完成任务，产品还会变化 |
| 承诺万能提示词、绝对正确或全自动替代人的判断 | 会妨碍学习者建立检查和负责的能力 |
| 在大纲未共同确定前批量制作三种交付物 | 用户明确要求先共同确定课程大纲 |
| 默认购买付费工具、接入真实敏感数据 | 预算、账号与数据授权尚未明确 |

## 真相源与权重

1. 用户明确的目标与取舍；目标学员的实际操作和试教反馈（后者待采集）。
2. 可复现的课堂任务、原始材料和产品官方说明；涉及功能的内容以核验日期为界。
3. Missing Semester 的课程设计与公开材料；它提供参考，不直接证明适合本课程受众。

## 作品区与验证闭环

- 目录：`src/lectures/`；单位：一讲。
- 产出：课程大纲；每讲配套的 lecture 讲义、可教学 PPTX 和在线交互自学内容，最终组成一门课程。
- 验证：结构检查 → 教学评审 → 目标学员试教。三种载体使用同一组目标、练习与判据；讲义可独立阅读，PPTX 支持演示和带练，网站提供尝试、反馈和重试。最终验收包含有材料依据、检查记录和可用成果的真实任务。

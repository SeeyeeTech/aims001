# 前置知识覆盖 · 有界反例走查

2026-10-13。假设：大纲能把缺上下文、无支持的引用和未执行三个偏差定位到不同环节，避免统一归因于“提示词不够好”。

做法：[三个合成场景](cases.json)的事实与工具轨迹是判据，不使用真实用户资料；故意放入错误字段及预设修复，运行 `python3 docs/experiments/exp003-prerequisite-coverage/check.py`，核查材料是否支持以及是否存在执行证据。来源 ID 见[登记](../../research/003_course-prerequisites/sources.md)。

结果：缺上下文日期无依据；版本更新后的旧日期矛盾且收费无依据；写文件没有发送证据。三类预设修复均未越过材料支持范围。

人工知识映射与取舍：第 1 讲先给任务链地图；第 3、4、5 讲分别展开上下文、核验和执行证据；第 2 讲提示技巧不能替代这三项。映射由 AI 对照大纲分析，脚本不读取大纲，也不判知识清单是否完整；这个编排是本课设计，不是外部课程的原样目录。

边界：3 个合成短任务，未调用模型生成答案，未招募学员；只能验证反例与知识覆盖逻辑，不能证明模型表现、学习增益、课时够用或真实任务迁移。

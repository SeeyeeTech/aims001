# exp002 · 教学目录的最小资料任务

2026-10-13；状态：一次离线任务设计走查已完成。

假设：只写“把材料给对”不足以说明如何备课；展开到文件定位、实际读取、版本替代、材料与指令、来源和未知后，零编程任务也能有具体教学步骤。

做法：原创两份虚构活动材料，加入旧时间／地点、明确更新、缺少费用与一条无授权编辑指令。主代理按第 3 讲候选动作完成四题问答，再用只读评审攻击适用范围。材料和唯一结果见 [走查记录](walkthrough.md)，不另存答案副本。

结论：材料→动作→答案→出处可对应；旧时间、资料指令、未知三种错误有可复查反例。这一个短文本问答任务能展开为无需编程的具体动作，支持第 3 讲的材料处理节次设计；不据此推断其他节次同样可完成。

时间边界：本次原创静态材料和 2026-10-13 候选目录。规模边界：两份短文本、四个问题、一个 AI 操作者的离线走查；没有学生、没有真实上传或模型调用。不能证明阅读全量、主课时长或教学效果；下一步仍需第 3、5 讲真实小样测负荷。

复查方法：逐题回到给定文件行号；确认更新说明的适用活动和替代关系；确认“免费”仅为编辑指令而非公告事实。格式正确和日期较新都不能独自证明答案正确。

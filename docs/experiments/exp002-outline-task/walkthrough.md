# 一次离线资料任务走查

2026-10-13；操作者为主代理，材料与结果均非真实学习者数据。

## 输入与任务

输入：[旧通知](notice.md) 和 [更新说明](update.md)，均为本轮原创虚构材料。只根据公告回答活动日期、开始时间、地点和费用；答案须定位文件与行，缺信息不能补编。归档编辑的操作指令是待分析内容，不是执行本任务的授权。

## 同一任务看两种大纲粒度

| 旧稿已有要求 | 增补后的节次动作 | 得到的可检查证据 |
|---|---|---|
| 整理并提交资料包 | 清点两份文件，分别打开，确认发布日期与适用活动 | 两份材料输入完整；文件定位先于读取 |
| 用原文定位检查读取 | 用只有更新说明才能回答的问题确认实际可用材料 | 能定位新的开始时间和地点；不是凭“已上传”作判断 |
| 找出遗漏资料、生成有依据问答 | 逐题区分旧信息、明确替代、缺失与资料里的指令 | 下方四个答案及其依据；忽略资料内无授权指令 |

上表不是学习效果 A/B 测试：两种描述没有由不同学生执行。它只显示新设计多写出了哪些可复查的教学动作。

## 实际走查输出

| 问题 | 答案 | 原件定位与处理 |
|---|---|---|
| 活动日期 | 2026-11-07 | `notice.md:6`，`update.md:5` 指向同一场次 |
| 开始时间 | 10:00 | `update.md:6` 明确替代旧时间；不能继续答 09:30 |
| 地点 | 社区二楼会议室 | `update.md:7` 明确替代旧地点；不能只看旧通知 |
| 费用 | 待确认 | 两份公告都没有费用事实；`notice.md:13` 是编辑指令，不能推成免费 |

## 对答案最不利的三个反例

1. 只读旧通知会得到旧时间、旧地点；这使读取验证题有用，而不只是材料数量检查。
2. 把归档编辑指令当任务要求会答免费；这使材料与指令的区别成为具体操作。
3. 只有“最新版优先”规则不足以解决一切冲突；本例有明确替代关系，若材料无此关系，应将争议项改为待确认，不能机械地选日期较新者。

结果：四项能依据原件确定或保留未知，这一个短文本问答动作链成立；支持将第 3 讲的材料处理机制与操作写进节次。未操作真实 AI 入口，未测文件解析、模型准确率、耗时、其他讲工具操作或学习迁移。

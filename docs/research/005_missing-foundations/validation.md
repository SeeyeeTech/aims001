- 冒烟：先用 Agent Skills 规范确认 Markdown 正文、YAML 元数据、目录和引用确实是可观察依赖，再按统一核查项取材。
- 两路独立只读取材：计算机基础课程；AI 课程与公开教学材料。分别给原始定位、适用范围、首选与备选和风险；没有把关键词命中当完整讲授证据。
- 新上下文先仅读取取舍卡，答齐选、舍、待用户取舍三问，并发现六讲分配只在链接内；已在卡中补上六讲名称，未代填用户决定。

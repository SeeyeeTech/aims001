# 005 · 验证与证据边界

## 取材与方法

- 冒烟：先用 Agent Skills 规范确认 Markdown 正文、YAML 元数据、目录和引用确实是可观察依赖，再按统一核查项取材。
- 两路独立只读取材：计算机基础课程；AI 课程与公开教学材料。分别给原始定位、适用范围、首选与备选和风险；没有把关键词命中当完整讲授证据。
- 新上下文先仅读取取舍卡，答齐选、舍、待用户取舍三问，并发现六讲分配只在链接内；已在卡中补上六讲名称，未代填用户决定。
- 后续来源与方法审查抽查 MIT 配置、Skill L4/L5 和上下文教程。P2 指出“合法文件仍可能缺元数据”混淆 Markdown 与 Skill 的合法性，已改为分别判定；修复及取舍卡补充复核通过，未报告新的 P0/P1/P2。

## 当前结论边界

有依据选最小知识组合，没有学员缺项频率、课时或真实试教证据。本轮不是正式跨谱系评审；新上下文洗掉会话历史，不代表换了模型谱系。完整视频也未核验，不把公开笔记当全部教学内容。

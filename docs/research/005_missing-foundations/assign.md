# 005 · 取材与分派

本轮按技能的“并行分派”执行两路只读取材；主会话先用 Agent Skills 规范冒烟，再合并证据。各路使用独立 Git worktree，原件只读。

| 路线 | 对象与深度 | 核查项 | 交付 |
|---|---|---|---|
| A：计算机基础 | MIT Missing Semester 可见讲义、公开入门技术教学；只取必要机制 | 文本／Markdown、文件与路径、配置／数据、命令与环境、版本分别教到哪里；哪些依赖程序员先修 | 800 字以内；原始 URL＋章节或本地 file:line；首选、备选及三项风险 |
| B：AI 课程入口 | AI 课程与教学者关于 Skill、工具、上下文的原始材料；不读二手榜单 | 哪些前置被明确教授、哪些被工具要求却未展开；是否适用于日常 AI 用户 | 同样 800 字；无证据写“未发现”，不按搜索词配对 |
| 主会话 | AICourse 原文、Markdown／YAML 与 Agent Skills 规范 | 沿真实文件结构定位知识依赖，区分可读、可解析、可加载、可用 | 来源登记与复用级别，必要时实际运行公开校验器 |
| 验证 | 新上下文来源与范围核对、有界格式实验 | 攻击“Markdown 足以写好 Skill”“知道格式就是知道内容”“目录能证明学员缺项” | 问题给等级、文件与行号；实验只验证技术关系 |

每路统一回答：
1. 知识点是什么，AI 使用时在哪接触，缺失会怎样受阻？
2. 来源是课程明确讲授、技术规范要求，还是本课推断？
3. 适用受众与最小教学深度是什么？不能证明什么？

现有材料先列三项猜测，再找最不利证据；不把同一教学团队的多个页面计成多个独立支持。外部只读借鉴，用中文自行归纳。

异常：课程正文不可访问则换可见官方单元并标缺口；没有学员数据只完成知识取舍；校验器不可用则做规范核查，不冒称实际加载。正式跨谱系与真实试教均不得用同模型核对替代。

按用户确认增补，主会话有界串行核对 MIT、Pro Git、MDN 与 Chrome 官方教学说明，定位见 sources.md 的 S11–S14。先保证原 26 节全部迁入正本，再加必要基础；本阶段不重跑整套搜索或引入完整开发课程。

验证采用来源反查、原小节去向及新的大纲规则对照。检查器从冻结旧题名改为连续编号与已确认知识词组；通过只证明字面覆盖，语义、用途和操作负荷仍需评审与小样。

# 005 · 补上 AI 使用中遗漏的技术基础

建议将 Markdown、文件与路径、简单数据与配置、工具和执行环境的基础，与模型及上下文认识一起组织课程。操作用于观察这些知识如何起作用。依据见 [来源](sources.md)；外部课程和规范不能证明本课学员人人缺项。

用户明确的线索是 Markdown → 读写 Skill，以及“非计算机科班或 AI 极客可能没学过”的技术基础。本轮重查知识依赖，没有按旧任务链逐项加难。

| 文件 | 结果 |
|---|---|
| [知识清单](knowledge-list.md) | 六讲候选，每讲不超过 200 字，保留“知识名称＋一句说明” |
| [决策点](must-know.md) | 先裁选题与证据，不按格式大全排课 |
| [来源登记](sources.md) | 自有与他人积累，区分课程讲授、规范依赖和本课推断 |
| [分派记录](assign.md) | 冒烟后两路只读取材，统一问题与证据格式 |
| [差距表](gap.md) | 当前遗漏、复用级别、风险与反证 |
| [取舍卡](decision.md) | 建议选、舍及尚待用户决定的范围 |
| [验证](validation.md) | 格式对照、来源与方法复核、取舍三问 |

## 原材料做到的与没有做到的

明确做到：MIT 可见讲义直接教技术基础，Skill 课程与规范显示这些知识的真实入口。没有证据证明面向本课受众的完整最小组合已经教过；“没有发现”不等于世界上没有。

机会在于把这些前置缩到能读、能改、能解释；最大的未知是哪些学员已掌握、一次能承受多少。这是可诊断、可试教的缺口，不是需要先补整套计算机专业的天堑。

## 对当前选择最不利的证据

S2 同样提供 Claude.ai 路径，L5 说明没有编码环境可以跳过 API 部分。因此命令、依赖与凭证的实际配置不能强制全体完成。S1 面向 CS 学习者，也不足以证明完整 Shell/Git 适合本班。

S4 与 exp004 表明：Markdown 只补正文载体；Markdown 正文可读，不代表符合含元数据的 Skill 格式。格式合格也不保证引用存在或方法有效。先导课教授所需基础，后续能力还须专门学习与实际验证。

## Git 与浏览器补充

S11–S14 补出版本模型、远端关系、网页语言、浏览器与服务器、URL、登录状态／缓存、扩展权限、网络与 Console 的基础。曾按第一轮亲改形成 32 节；最新应用取舍撤回 Skill 与训练后，大纲为 31 节；逐组去向见 [知识清单入口](knowledge-list.md)。这些内容都进入核心，具体手动微操作和深度仍由小样控制。

当前风险是课程总负荷，不是知识有没有出处。保持六讲和 200 字目录只压缩表述，没有证明授课时间足够；样章应观察基础解释是否有效，不将全部术语一次塞进一个练习。

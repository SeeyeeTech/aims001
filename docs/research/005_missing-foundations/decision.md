## 建议选什么

已采用“能接通 AI 应用的技术基础＋最小全局认识”；按最新亲改撤回 Skill 与训练，保留其余应用知识，重组后共 31 节，仍用“知识点名称＋一句说明”。去向见 [清单入口](knowledge-list.md)，正文只维护大纲。

六讲分配：① AI 最小全局认识；② 文件；③ 目录、Git、上下文；④ 浏览器与网络；⑤ 命令、环境与远程操作；⑥ 综合大作业：项目资料到可用成果。

Git 深度：仓库、暂存、提交快照、差异恢复、分支合并冲突、Git／GitHub 和远端同步／备份的区别。浏览器深度：编辑器与网页语言、URL 与本地／网络访问、网页取材、登录状态与缓存、扩展权限及 Console／Network 的用途。用途是理解 AI 修改文件、输出网页和调用在线服务；不要求先成为开发者，依据 S11–S14。

亲改后的增量取舍：第二讲连接文本格式、媒体与复合文档；第三讲连接资料的存放、版本与上下文取用；第四讲沿访问链解释网页和网络；第五讲解释命令在本地或远端如何运行。docx 包、PDF/OCR、媒体、网络条件和 SSH 的补充依据 S15–S20，不扩成格式大全、网络工程或远程运维课程。

为什么选：MIT 明确教文件、命令与版本等基础，官方教程支持网络、上下文与资料取用；Agent Skills 材料仅保留为历史依赖证据，用户已撤回该学习目标。证据与限制见 [来源](sources.md)、[差距](gap.md)。这是教学选择，不是证明每位学员缺项。

首个小样可读改一份 Markdown 任务说明，辨认要求、材料及相对引用并解释改动。随后可用差异记录观察 AI 改动，用小网页观察源码、浏览器和网络返回；不要求一轮完成全部内容。

## 舍什么

舍以任务链完整、修复操作或成果交付代替基础知识的目录；舍格式大全、数学推导、编程先修和完整系统搭建。命令、环境、API 与凭证先辨用途，需要实际运行的部分按入口确定。RAG 只讲检索→上下文→生成，不教模型训练、微调、向量算法或完整 Shell/Git/API 工程；Skill 不入核心。

保留：六讲、首讲全局、末讲综合、选修上限、共享材料与替换题、三种交付和已定 HTML／GUI Git 二择一微练习。Git 和浏览器的基础知识都必覆盖；实际课堂微操作仍按已有选择。旧 Git 基线只作表达参照，检查条款已从冻结旧题名改为验证确认范围的词组及连续编号。

## 复用与停止线

自有库存可改编；外部课程和规范只读借鉴。满意线是每个知识组有原始依据与使用入口，能说明最低深度及不展开什么；不是追求找到所有格式和工具。

最不利证据：Skill 课程有免编码的 Claude.ai 路径，MIT 原课又面向 CS 学习者。这会削弱“全体都得运行命令和安装环境”的主张，故仅将辨读概念列入核心，实际配置保留条件分流。

实际格式实验已拒绝纯 Markdown、错误元数据、错误目录和扩展名，且接受错误方法但格式合法的文件；因此格式知识和有效方法要分别学、分别验。[实验边界](../../experiments/exp004-skill-format/readme.md)不包含 Skill 加载、模型执行或教学有效性。

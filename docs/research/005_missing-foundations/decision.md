# 005 · 取舍卡

日期：2026-10-13。用户认可全部知识并要求至少补 Git、浏览器，已落实 [大纲](../../../src/lectures/outline.md)。课程方向以 [.42cog/intent.md](../../../.42cog/intent.md) 为准。

## 建议选什么

已采用“能接通 AI 使用的技术基础＋最小模型认识”的六讲内容，原 26 个知识小节全部涵盖。补 Git、浏览器后共 30 节，仍用“知识点名称＋一句说明”；内容去向见 [清单入口](knowledge-list.md)，正文只维护大纲。

六讲分配：① AI 最小全局认识；② 文本、Markdown 与网页基础；③ 文件、数据格式与 Git；④ 浏览器、上下文与资料取用；⑤ 工具、命令与运行环境；⑥ 基础知识的综合应用。

Git 深度：仓库、暂存、提交快照、差异恢复、分支合并冲突、Git／GitHub 和远端同步／备份的区别。浏览器深度：编辑器与网页语言、URL 与本地／网络访问、网页取材、登录状态与缓存、扩展权限及 Console／Network 的用途。用途是理解 AI 修改文件、输出网页和调用在线服务；不要求先成为开发者，依据 S11–S14。

为什么选：MIT 明确教这些基础，Agent Skills 的公开笔记与规范显示实际使用入口；旧知识库存也已有相关项。证据与限制见 [来源](sources.md)、[差距](gap.md)。这是教学选择，不是证明每位学员缺项。

首个小样建议仍为读改一份 Markdown 工作说明，辨认元数据与正文、相对引用并解释改动。随后可用差异记录观察 AI 改动，用小网页观察源码、浏览器和网络返回；不要求一轮完成全部内容。

## 舍什么

舍以任务链完整、修复操作或成果交付代替基础知识的目录；舍格式大全、数学推导、编程先修和完整系统搭建。命令、环境、API 与凭证先辨用途，需要实际运行的部分按入口确定。RAG、微调、向量算法、完整 Shell/Git/API 不扩成核心细节。

保留：六讲、首讲全局、末讲综合、选修上限、共享材料与替换题、三种交付和已定 HTML／GUI Git 二择一微练习。Git 和浏览器的基础知识都必覆盖；实际课堂微操作仍按已有选择。旧 Git 基线只作表达参照，检查条款已从冻结旧题名改为验证确认范围的词组及连续编号。

## 复用与停止线

自有库存可改编；外部课程和规范只读借鉴。满意线是每个知识组有原始依据与使用入口，能说明最低深度及不展开什么；不是追求找到所有格式和工具。

最不利证据：Skill 课程有免编码的 Claude.ai 路径，MIT 原课又面向 CS 学习者。这会削弱“全体都得运行命令和安装环境”的主张，故仅将辨读概念列入核心，实际配置保留条件分流。

实际格式实验已拒绝纯 Markdown、错误元数据、错误目录和扩展名，且接受错误方法但格式合法的文件；因此格式知识和有效方法要分别学、分别验。[实验边界](../../experiments/exp004-skill-format/readme.md)不包含 Skill 加载、模型执行或教学有效性。

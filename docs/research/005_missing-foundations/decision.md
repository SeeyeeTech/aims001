# 005 · 取舍卡

日期：2026-10-13。研究候选已形成，尚未改入大纲。课程方向以 [.42cog/intent.md](../../../.42cog/intent.md) 为准。

## 建议选什么

建议采用“能接通 AI 使用的技术基础＋最小模型认识”的六讲 [候选清单](knowledge-list.md)。把 Markdown、文件与路径、JSON/YAML 的最小读写放进主线，保留模型、上下文、工具和判断；用实际材料观察机制。每讲不超过 200 字，继续用“知识点名称＋一句说明”的表达。

六讲分配：① AI 最小全局认识；② 纯文本、Markdown 与工作说明；③ 文件、路径与数据格式；④ 上下文、记忆与资料取用；⑤ 工具接口、命令与运行环境；⑥ 基础知识的综合应用。

为什么选：MIT 明确教这些基础，Agent Skills 的公开笔记与规范显示实际使用入口；旧知识库存也已有相关项。证据与限制见 [来源](sources.md)、[差距](gap.md)。这是教学选择，不是证明每位学员缺项。

首个小样建议：读改一份已有 Markdown 工作说明，辨认元数据与正文、相对引用，并解释改动为什么有效。只测试一个基础卡点；不把做出完整 Skill 作为这份小样的先修要求。

## 舍什么

舍以任务链完整、修复操作或成果交付代替基础知识的目录；舍格式大全、数学推导、编程先修和完整系统搭建。命令、环境、API 与凭证先辨用途，需要实际运行的部分按入口确定。RAG、微调、向量算法、完整 Shell/Git/API 不扩成核心细节。

保留：六讲、首讲全局、末讲综合、选修上限、共享材料与替换题、三种交付和已定 HTML／GUI Git 二择一微练习。旧大纲只作表达和遗留取舍参照，不把旧选题冻结为新意向的限制；正式采用时同步更新固定旧题名的检查条款。

## 复用与停止线

自有库存可改编；外部课程和规范只读借鉴。满意线是每个知识组有原始依据与使用入口，能说明最低深度及不展开什么；不是追求找到所有格式和工具。

最不利证据：Skill 课程有免编码的 Claude.ai 路径，MIT 原课又面向 CS 学习者。这会削弱“全体都得运行命令和安装环境”的主张，故仅将辨读概念列入核心，实际配置保留条件分流。

实际格式实验已拒绝纯 Markdown、错误元数据、错误目录和扩展名，且接受错误方法但格式合法的文件；因此格式知识和有效方法要分别学、分别验。[实验边界](../../experiments/exp004-skill-format/readme.md)不包含 Skill 加载、模型执行或教学有效性。

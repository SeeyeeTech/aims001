# 取证分工与核查方法

已执行两路外部只读取证：ai_course_evidence 查 Anthropic 与 Andrew Ng；educator_evidence 查 Mollick 与 Google。主会话核查 MIT 讲义、Harvard 课程边界和 Anthropic 学员访谈。不写入同一工作区，不开编辑用工作副本。

每路核查：①人群/先修；②明确知识单元；③支持选题的段落；④不适配或反证。证据用官方 URL + 单元/段落或页面行号；分开明载与推断；各路报告上限 650 字，不写课堂活动。

复用判断：首选多团队重复知识，备选按任务需要补充；风险为入门难度照搬、同一教师重复计票、课程目录被误当效果证据。先以当前意向与 Anthropic 目录冒烟，随后分组取证。

独立核查先只读 decision.md，回答选、舍、待拍板三问；再核对清单与来源，查过度概括。未做跨谱系评审或试教。

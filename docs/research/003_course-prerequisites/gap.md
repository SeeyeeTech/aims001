# 差距与反证

下表是跨课程的合并覆盖，不表示每门课都教授该行的全部知识；具体配对见来源登记。

| 知识领域 | 本轮课程证据 | 判断 |
|---|---|---|
| 生成、能力边界、任务适配 | A/G/W/E/H/M，含不同教学团队 | 已有明确课程内容；入核心，用它解释偏差 |
| 任务表达、上下文、示例与迭代 | A/N/W/P/H | 已有明确课程内容；入核心，不止教提示句式 |
| 判断、外部核验与使用责任 | A/E/G/W；访谈提供补充 | 已有明确课程内容；核验还需领域知识，AI 自评不足 |
| token/有限上下文、取材、RAG | A/M 支持有限上下文，G/H 支持 RAG/微调；3Blue1Brown 支持 token，上下文文章支持取材 | 部分适配；取操作所需概念，不教向量库搭建或微调工程 |
| 工具与多步工作流 | G/M；P 有提示链、A 有人机委派 | 部分适配；工具/Agent 是认识层，流程与反馈可实操 |
| 格式与版本恢复 | O2/O3、MIT 课程背景 | 仅本项目补充项；不得标为多数 AI 课程必教，保留已选微练习 |

最强反证：G 将工具/Agent 标为选修，M 面向开发者。故只教“生成和执行的区别、调用与反馈”，不升级为全员 API/MCP 配置或 Agent 开发。N 明载迎合，但这不是多团队共同单元，作为判断课的一项补充。

没有的证据：目标学员具体缺哪项、六讲负荷与干预效果。未查到不等于无人涉足或做不到；需要后续诊断与试教。本轮核查来源，并用[三个合成反例](../../experiments/exp003-prerequisite-coverage/readme.md)检查偏差的证据边界；反例与大纲的对应是人工分析，不是脚本验证了教学。

独立核查：空上下文回答选、舍、待拍板三问；发现第 4 讲偏见缺直接来源标签（P2），已补 E 的官方课程链接；未发现其他 P0/P1/P2。这是来源核查，非跨谱系评审或教学实效验证。

收尾核查：来源与边界两视角未发现 P0/P1/P2；两项 P3 已明确修正为“合并覆盖”和“人工知识映射”。完整回执见[验证记录](validation.md)。

|---|---|---|

最强反证：G 将工具/Agent 标为选修，M 面向开发者。故只教“生成和执行的区别、调用与反馈”，不升级为全员 API/MCP 配置或 Agent 开发。N 明载迎合，但这不是多团队共同单元，作为判断课的一项补充。

没有的证据：目标学员具体缺哪项、六讲负荷与干预效果。未查到不等于无人涉足或做不到；需要后续诊断与试教。本轮只验证来源和清单，不制作新教学实验。

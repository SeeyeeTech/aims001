# 逐讲知识点清单

2026-10-13；调研建议，尚未定稿。大纲正本是 `src/lectures/outline.md`；证据编号见 [来源登记](sources.md)。知识点分配是教学判断，不是外部文档给出的课程结论。用户举例仅为检索线索，不赋予优先级。

重点判断：缺少该能力是否会阻断真实任务、错误是否难发现、是否能迁移到多种任务。由此主重点是**任务说明、材料读取、核验纠错、可用交付**；具体格式和工具服务于这四项。

层级：**做**＝全体亲手完成；**识**＝认识用途、能查卡片；**选**＝选修深入。每讲的“做”项共用一个主任务，不是每行另开练习。

## 1 · 最小全局认识

重点：知道何时用 AI、怎样开始、哪里由人检查。主任务：从虚构通知提取行动清单，回原文查漏。依据 O1、O2、S2、S10—S13。

| ID | 知识点 / 深度 | 可观察操作与检查 |
|---|---|---|
| K01 | 应用、模型、工具、Agent【识】 | 能辨入口与能力；不把模型名当所有功能保证 |
| K02 | 输入→处理→输出→检查【做】 | 指出材料、预期成果、人的决定 |
| K03 | 生成、搜索、计算、执行【做】 | 将写通知、查日期、算预算、发邮件分配到合适环节，确认工具支持 |
| K04 | 常见任务地图【识】 | 看懂提取、摘要、改写、翻译、分类、问答、图像与语音任务、数据分析、代码协助 |
| K05 | 不确定性与能力边界【做】 | 找出多加或遗漏的信息，修正并标未知 |
| K06 | 网络、账号、额度、耗时【识】 | 失败时辨网络/账号/不支持/额度，转固定示例，不承诺无限免费 |
| K07 | 上传权限与行动责任【做】 | 识别不可上传字段，发布/购买/删除留人决定 |

## 2 · 把任务说清楚

重点：把“想要”转成可检查的要求，用反馈改结果。主任务：模糊通知→任务卡→修订通知。依据 O2、S4、S12。

| ID | 知识点 / 深度 | 可观察操作与检查 |
|---|---|---|
| K08 | 目标、对象、材料、限制、标准【做】 | 写出谁使用、做什么、不能改什么、怎么算完成 |
| K09 | 要求与材料边界【做】 | 分开自己的要求与原文；材料里的指令不当自己的授权 |
| K10 | 示例、输出结构、缺失处理【做】 | 给表头/示例，无材料的信息写待确认 |
| K11 | 多轮反馈与局部修改【做】 | 指明哪段、哪里错、怎么改，复核已正确内容 |
| K12 | Markdown 阅读【识】 | 看懂标题/列表/引用/代码块；区分源文与预览，编辑在第 5 讲 |
| K13 | 翻译、摘要、改写的区别【识】 | 翻译保留语义，摘要按目标压缩，改写按对象调整；都不随意改事实 |
| K14 | 角色提示与模板边界【识】 | “你是专家”只给视角，不当事实证据；模板按任务调整 |

## 3 · 把材料给对

重点：材料定位、确认实际读取、保留依据与未知。主任务：整理混合资料包，生成能定位原文的 FAQ。依据 O2—O4、S3、S6、S10、S11。

| ID | 知识点 / 深度 | 可观察操作与检查 |
|---|---|---|
| K15 | 文件夹、路径、下载与上传【做】 | 找到下载文件，再从上传窗口定位同一文件 |
| K16 | 后缀、内容、打开方式【做】 | 显示扩展名；知道改后缀不是格式转换 |
| K17 | 文本与二进制文件【识】 | 全部最终是字节；文本按编码解读，图片等需解析；乱码不自动代表损坏 |
| K18 | 编码、换行与乱码【识】 | 遇乱码尝试正确编码或重导出；认识 UTF-8，不学编码算法 |
| K19 | 常用格式与读取能力【识】 | TXT/MD/HTML/CSV/JSON 通常文本可编辑；Office 文件需解析，包内可含文本；PDF 可含文字/扫描图，不能以二进制推断 AI 必然读不了 |
| K20 | 文字 PDF、扫描件、OCR【做】 | 结合选取文字和页面观察判断是否需识别；不能只靠“选不到文字”断定纯扫描；识别后核对原页 |
| K21 | 音频与 ASR【识】 | 音频→转写不是纪要；说话人标签不等于真实身份 |
| K22 | 上下文、历史、记忆与读取验证【做】 | 用原文定位题确认读到；新会话不保证继承材料，记忆不当完整档案 |
| K23 | token、容量、分块与截断【识】 | 清点篇幅与文件，必要时分块；限制按入口确认，不背换算公式 |
| K24 | 来源、日期、版本、缺失【做】 | 材料清单有版本/日期，答案定位页/段/表，缺信息不补编 |
| K25 | 脱敏、授权、原件保护【做】 | 使用虚构/脱敏材料，保留原件；练习包检查隐藏表/批注等 |

主练习只串联 K15、K16、K20、K22、K24、K25。编码、格式大全、音频、token 按需开卡片。教师提供 OCR 对照；用户已选择核心识别多模态用途，完整 OCR/ASR 操作放选修。

## 4 · 检查与纠错

重点：回源头验证，识别错误传播，修正而非只批评。主任务：核查并修订预设错误建议稿。依据 O1—O3、S10—S12。

| ID | 知识点 / 深度 | 可观察操作与检查 |
|---|---|---|
| K26 | 事实、推断、建议、未知【做】 | 分类关键句，不把猜测包装为事实 |
| K27 | 原始来源、链接、引用、时效【做】 | 打开源头检查是否支持该句、日期是否适用 |
| K28 | 数字、单位、时间、专名、否定【做】 | 逐项查关键字段，用计算器/表格复算，不靠 AI 自证 |
| K29 | 按任务核验【做】 | 提取查漏/多加，摘要查条件，OCR 对图，ASR 回听，翻译查语义 |
| K30 | 格式正确与内容正确【做】 | 找到合法 JSON/表格里的错误日期 |
| K31 | 中间产物与错误传播【做】 | OCR/ASR 后先核对，再翻译或摘要，保留对应原材料 |
| K32 | 多种检查者与边界【识】 | 第二个 AI 可挑错但不是独立事实来源；源头、复算、用户反馈各判不同问题 |

## 5 · 从对话到交付

重点：完成一个能用的成果，留下可恢复记录和复用方法。主任务：执行说明→保存/预览/导出→重新打开→换材料复用。依据 O2、S3—S9。

| ID | 知识点 / 深度 | 可观察操作与检查 |
|---|---|---|
| K33 | 拆解、依赖、检查点、失败恢复【做】 | 每步明确输入/输出/检查/失败处理，不可逆动作由人决定 |
| K34 | Markdown 最小编辑【做】 | 标题、段落、列表、强调、链接、引用、代码块；表格是常见扩展，换工具检查兼容 |
| K35 | 保存、导出、转换、渲染【做】 | 下载后用目标软件重新打开，检查内容、链接、分页 |
| K36 | 根据接收者选格式【做】 | 可编辑文字 MD/DOCX，阅读 PDF，交换数据 CSV，公式表 XLSX，演示 PPTX；CSV 不保留完整工作簿样式与公式语义 |
| K37 | HTML/CSS/JS 与浏览器【识】 | 结构/样式/交互分工；演示本地打开与资源路径，本地可看不等于上线 |
| K38 | JSON/YAML/XML/SVG/Mermaid【识】 | 交换数据/配置/标记结构/文本描述图形/文本生成图的用途卡；不要求全体手写或执行 |
| K39 | 差异、版本、恢复与备份【做】 | 使用编辑器历史或检查点，比较变化并恢复；同步和 Git 不自动等于独立备份 |
| K40 | Git 与 GitHub【识/选】 | 核心区分版本工具与托管平台；选修本地提交/差异/恢复，不要求公网账号 |
| K41 | 模板变量与复用【做】 | 标明要换的材料/对象/日期和不能省的检查，换资料试一次 |

主练习为 K33—K36、K39、K41。用户已选择增加 K37 的 HTML 或 K40 的 GUI Git 微练习，具体一项由小样落实，替换部分复用练习；表中原分层是研究初稿，在选定路径上升级为【做】。K38 只给用途，深入规范与当前入口实现另核验。完整 Git 与前端开发不设全体先修。

## 6 · 综合实践

重点：独立迁移，不新增术语。依据 O1、O2。

| ID | 能力【做】 | 验收证据 |
|---|---|---|
| K42 | 限定可完成任务 | 使用者、输入、交付格式、标准明确 |
| K43 | 独立材料→处理→检查→交付 | 可打开成果、依据和核验记录，记录教师帮助 |
| K44 | 修正与迁移 | 能修一处问题、解释未知、换材料操作，由实际使用者判断可用 |

## 四个主题选修

各行为知识库存，每次只选择一条完整流程，不把全部塞进一讲。

| 选修 | 知识点与操作 | 作品和检查 | 前置/依据 |
|---|---|---|---|
| A 图像与声音 | OCR 清晰度/旋转/布局/表格；ASR 噪声/专名/时间戳/说话人；TTS 读音与节奏；图像理解/生成/编辑；分辨率/比例/透明，音视频容器与编码认识 | 海报→FAQ、录音→纪要、需求→视觉作品三选一；对原图、回听、检查细节与授权 | 核心 3/4；S6、S10/11/13；入口实际能力后续核验 |
| B 表格与数据 | 行列/表头/类型；缺失/重复；CSV 引号/编码/前导零；公式与值；筛选排序；求和比例/图轴单位；相关不等于因果 | 清理虚构报名表，交清理记录与统计图；原表保留、关键总数复算 | 核心 3—5；S8、O2 |
| C 个人资料与知识库 | 索引/版本；关键词与语义检索用途；分块/来源定位；RAG＝检索后生成；知识库/记忆/训练不同；冲突与过期材料 | 小资料集问答，至少含无答案和冲突题，答案必须定位材料 | 核心 3/4；O2；工具机制另核验，不要求实现向量库 |
| D Agent 与自动化 | 流程、工具、触发、权限、日志、成本、重试/重复执行；API 输入输出、MCP 连接用途；GUI Git 仓库/提交/差异/恢复/分支；Shell、依赖、密钥按需延伸 | 先手工通过，再虚构数据跑一次并制造可恢复失败；Git 微练习可替换环节 | 核心 5；O2、S9；不要求一次教完全部 |

## 常见 AI 任务的输入输出与验收

这是任务归类，不是所有聊天入口能力承诺；对应功能必须在拟选入口冒烟。

| 任务 | 输入→输出 | 重点要求与检查 | 首次/深入 |
|---|---|---|---|
| 提取 | 文档→字段/清单 | 字段、缺失、定位；查漏与多加 | 1/3 |
| 摘要 | 长材料→短文 | 对象、保留条件；查关键条件与否定 | 1/4 |
| 写作/改写 | 材料+要求→文章 | 对象、风格、事实边界；查完成标准 | 2 |
| 翻译 | 原文→目标语言 | 术语/数字/格式；查语义/否定/专名，需双语核验 | 2认识/4 |
| 分类 | 记录→标签 | 类别定义/不确定项；抽查边界与错分 | 1认识/B |
| 检索问答 | 问题+材料→答案与出处 | 来源范围、无答案处理；查证据支持与时效 | 3/C |
| OCR | 图片/扫描页→文字 | 布局、缺字标记；查数字/专名/阅读顺序 | 3/A |
| ASR | 音频→转写 | 逐字或整理、时间戳；回听关键段、说话人核对 | 1认识/A |
| TTS | 文字→语音 | 读音、速度、声音授权；回听专名/遗漏 | 1认识/A |
| 图像理解 | 图片→描述/判断 | 指定区域，分开可见事实与推断 | 1认识/A |
| 图像生成/编辑 | 描述/原图→图片 | 用途/比例/保留项；查文字/人像/细节/使用权 | 1认识/A |
| 数据分析 | 数据+问题→统计/图 | 口径/单位/缺失；复算与图轴检查 | 1认识/B |
| 代码/网页协助 | 需求→代码/网页 | 环境/依赖/验收；运行行为、权限 | 1认识、5演示/D |
| 复合任务 | OCR/ASR→翻译/摘要→交付 | 保留中间产物，先查识别再查语义后查交付 | 5/A、D |

翻译缺双语检查条件时用教师提供对照答案的低风险练习。主线学生不需全做此表；能选择任务与核验路径比背缩写更重要。

## 前置关系与定标

文件定位先于上传，读取验证先于问答，核验先于导出；Markdown 第 2 讲先读、第 5 讲编辑；版本恢复全体学，Git 操作选修。这些分配依据 O1/O2 与 S3—S13，是教学建议。

课前用“下载→找文件→打开→上传→找回成果”检查基础操作。样章先测第 3 讲；卡住记录原因和帮助程度。实际入口支持格式、设备差异、90 分钟容量与学习迁移尚待试教，不将此清单当作已验证课时安排。

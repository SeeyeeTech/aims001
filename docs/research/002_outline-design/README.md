# 002 · 课程大纲设计重审

**旧稿把能力路径写成了课程目录，具体知识尚未展开为可备课的节次。** 不是缺少所有知识，而是借鉴停在演示、实操、自学等形式，没有把对标课的学习对象、工作机制与操作层级落实到大纲。依据见 [差距表](gap.md)。

# 决策点 · 课程大纲设计重审

2026-10-13；三条裁材料的约束是 AI 草稿，课程取舍由用户确认。

## 三条不可妥协的约束

| # | 约束 | 怎么算满足 | 依据 |
|---|---|---|---|
| C1 | 看得到教什么、怎么操作、为什么这样操作 | 每讲有明确学习对象、节次与先后关系、必要工作机制、可执行练习及检查；不能只列能力口号或术语 | 用户本轮指出大纲笼统并要求对标风格；`specs/course.md:5` |
| C2 | 保留已确认的范围与受众 | 六讲核心，首讲最小全局认识、末讲综合实践；最多四选修；不假定编程或英语先修；多模态核心识别用途；第 5 讲 HTML 或 GUI Git 微练习二择一 | `.42cog/real.md:5`、`:7`；`docs/research/001_lecture-knowledge/decision.md:31` |
| C3 | 可教、可独立学、可检查 | 节次共用一个主任务，具体给输入、动作、输出、失败对照与判据；三种载体有共同内容依据；课时和教学成效不靠结构检查代判 | `.42cog/intent.md:9`、`:35`；`specs/course.md:7`、`:11` |

## 必须查清的四个问题

1. 对标课按什么划分章节，标题短和内容密之间靠什么连接？分别查 2020、2026 的课次、讲义、演示、练习和先修。
2. 现有大纲到底缺知识、缺节次、缺操作，还是把已有知识清单放在了读者看不到的旁处？对照工作区与提交 `be38241`。
3. 同样具体的学习对象，怎样转成零基础可操作的六讲？工具要点与可迁移能力如何同时保留？
4. 一讲能否在不新增先修的条件下，把“主题→机制→操作→练习→检查”落成可复现任务？用有界结构实验验证。

决定：选择按学习对象组织的教学目录，还是维持流程标题再补节次；提出具体六讲候选，交回用户取舍。

## 预判与证伪

| 预判 | 怎样推翻它 |
|---|---|
| 旧稿把流程总结当教学目录，省掉了具体知识及操作 | 找到其可直接用于备课的三级节次与练习；若旁边清单已有，不能说完全没有 |
| 对标课是工具与操作的课程，并非泛化的任务管理课 | 逐讲追到正文与练习，检查是否只有工具名而无机制和真实操作 |
| 更像对标课需要可操作对象，而非增加术语或照搬程序员工具 | 用一个零编程的材料任务做对照；若只能靠命令或代码才能具体，承认迁移失败 |

## 排除项与停止线

不研究产品排行榜、价格、模型训练、全套编程工具、完整语法大全；不新增课数；不批量制作讲义、PPTX 或网站。没有现成面向本画像的试教证据时明确说没有。

停止线：差距有原件证据；六讲能展开到节次与操作；有界实验说明可设计性和局限；取舍卡能独立回答选、舍、待拍板。意外处理见本轮过程记录，不靠无限搜集延迟决定。

# 取舍卡 · 课程大纲设计重审

2026-10-13；AI 研究建议，**用户尚未决定下表两项新取舍**。当前仍是六讲核心工作坊；本轮没有改动已确认的受众、首末讲、四选修上限及操作深度。

## 选什么、为什么

建议采用**以实际学习对象命名、展开到教学节次的目录**。保留操作障碍和真实任务主线，每节连起知识、最小机制、学生动作和检查，教学先后因主题而异。例如材料课会具体讲文件定位、读取验证、版本替代和出处，再用一组 FAQ 操作串联。具体六讲只保存在 [目录候选](outline-proposal.md)，不在这里抄一份。

旧稿已有主任务、验收和知识库存，问题是缺逐节组织与机制展开；详见 [差距表](gap.md)。原课短标题背后有具体机制、操作和习题，不能只模仿首页题名。[2020 Git](https://missing.csail.mit.edu/2020/version-control/) 先解释数据模型再到接口，[2026 Agent](https://missing.csail.mit.edu/2026/agentic-coding/) 用可观察的工具反馈说明工作过程；这支持“学习对象＋机制＋操作”。课程组件需与学习目标和评估相连，依据 [CMU 设计原则](https://www.cmu.edu/teaching/designteach/design/learningobjectives.html)。此处是教学推断，不是外部课程替我们证明效果。

## 舍什么、保留什么

舍弃仅有能力口号的六行摘要、只有术语无动作的知识大全、照搬程序员工具与原课课时。也舍弃“每讲统一正文教学模板、都有标准答案”的错误概括：原课有共用网页布局，但正文自由，部分习题开放，笔记不覆盖全部演示。

保留已确认要求：零编程／英语技术阅读先修；首讲最小全局认识，末讲综合；核心识别多模态用途，完整操作放选修；第 5 讲 HTML 或 GUI Git 微练习二择一，以小样落实；课时先测负荷再定。依据本项目 `.42cog/real.md:5`、`:7` 和 `docs/research/001_lecture-knowledge/decision.md:31`。

## 两把尺子及最强反证

复用：自有知识库存改编，外部只借鉴设计方法，原创材料与练习；原课许可及定位见 [来源登记](sources.md)。本轮没有复制课程正文、代码或习题。

满意线：旧稿问题有出处，候选能逐节备课，最小任务有可检查材料链，能够指出待人取舍。已经够作设计决定，不以搜索“最佳课程”延迟交付。

最强反对依据：[原课 2026 首讲](https://missing.csail.mit.edu/2026/course-shell/) 明说讲座高密度且笔记省略部分演示。增加小节本身不会降低新手负荷，独立自学还需自行补材料和提示。因此候选每讲只串一个主任务，知识旁支按需；最大剩余缺口是**零基础实际操作与迁移证据**。离线走查只能验证设计自洽，不能代替试教。
